# Problem

Create a simple web application without too much clutter. We do not wish to catter to everyone, we only wish to return to a simple single-minded easy to read layout without much possibilities.

# Personas

## Persona 1 : Bobby Whitaker

He is a consultant from W3C (World Wide Web Consortum). He joined early around 1995 
And he wants to be taken back to the first websites that appeared on the web, when CSS first came out. He is tired of the featured cluttered pages and want to have a simple application to keep a list of the books he reads without too much features.

## Persona 2 : Manuel Gardner

For Manuel today, it is hard to find an open-source application that doesn't have too many options. 
And he doesn't like application that evolve and change every years. While we can find them on phone application, often he finds himself using his webbrowser, so he would like to find one accessible publicly on his browser.

# Run manually :

You will need to first need to open a CMD inside the project folder then you can execute the three following commands and follow the instructions to host locally the site.

```shell
npm install
npm run build
npm run preview```
